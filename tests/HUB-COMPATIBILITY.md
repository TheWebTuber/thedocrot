# Thedocrot scan-depth compatibility correction

15 November 2026. Phase 2 explicitly permits a strictly necessary Hub compatibility fix.

The committed original Thedocrot `js/app.js` scans up to three upload pages (150 IDs) to find uploads and completed stream replays. Phase 1's Hub configuration still set Thedocrot `scanPages` to 2 (100 IDs). Migrating unchanged could lose replay discovery in uploads 101–150.

Only `CreatorPromote-API-Hub/config/channels.json` was changed in the Hub during Phase 2: Thedocrot `scanPages: 2` became `scanPages: 3`. No other creator setting or Hub source was changed. Existing `latestCount: 60` remains; the shared client is an exact copy of the Hub client. This setting has not been deployed. It adds at most two list requests per scheduled run (96 per day at 48 runs), making the previous documented network estimate approximately 2,016 units/day in its upper normal case instead of 1,920. Actual API usage and account quota were not measured.

The local proposed fixture was generated by the improved Hub with three scan pages configured. Before full-parity website deployment, deploy the improved Hub through a separately approved process and confirm its catalog and scan depth. Current production remains usable but exposes only six uploads, limiting category coverage.
